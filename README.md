# Boreal Plating — Website V2

Website institucional da **Boreal Plating**, desenvolvido para apresentar a empresa, suas capacidades industriais, processos, P&D, certificações, ESG, fornecedores, contato e oportunidades de carreira.

> **Esta é a versão 2 do website institucional da Boreal Plating.**
>
> 

---

## 📌 Sobre o projeto

O **Boreal Plating Website V2** foi desenvolvido como um site institucional responsivo, com foco em:

- apresentação da empresa;
- história e trajetória;
- capacidades industriais;
- tratamento de superfícies;
- usinagem;
- fabricação de componentes;
- P&D;
- ESG;
- certificações;
- fornecedores;
- contato;
- carreiras.

A versão 2 também aprimora a experiência visual do site, utilizando imagens reais da Boreal Plating, seções com maior destaque visual, animações sutis e uma estrutura de navegação mais organizada.

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias web nativas:

- HTML5
- CSS3
- JavaScript
- SVG
- Responsive Design

Não são utilizados frameworks como React, Vue ou Angular.

O projeto possui estrutura estática e pode ser hospedado em serviços como Vercel ou outros serviços compatíveis com sites estáticos.
